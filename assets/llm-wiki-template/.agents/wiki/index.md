# 위키 색인

위키 문서를 찾는 단일 색인이다. 구현 상태와 제안은 해당 문서에서 확인한다. 양식·임시 자료·캐시는 내용 색인에 넣지 않는다.

## 운영과 기준

| 문서 | 범위 |
| --- | --- |
| [README.md](README.md) | 위키의 목적과 근거·지식·운영 규칙의 관계. |
| [project.md](project.md) | 프로젝트 목적·범위·자료 경계·실행과 검증 기준. 미작성 양식에서 시작한다. |
| [wiki-schema.md](wiki-schema.md) | 근거·상태·문서·링크·색인·이력의 작성 기준. |
| [wiki-maintenance.md](wiki-maintenance.md) | 자료 반영·질문·코드 동기화·정합성 점검 절차. |
| [log.md](log.md) | 실제로 수행한 중요한 지식 변경과 점검의 시간순 이력. |

## 프로젝트 지식

확인한 주제를 만들 때 링크와 한 줄 범위를 추가한다. 아직 없는 문서를 링크하거나 예정 기능을 현재 구현으로 소개하지 않는다.
