# 프로젝트 위키

다음 작업에서 같은 근거를 다시 조합하지 않도록 프로젝트의 사실·결정·제약을 연결해 유지한다. 목적·포함 범위·자료 경계는 [project.md](project.md)에 둔다.

## 세 층의 관계

| 층 | 역할 |
| --- | --- |
| 근거 자료 | 코드·테스트·사용자 결정·원문·참고 자료. 자료가 주장하는 내용과 실제 확인한 내용을 구분한다. |
| 위키 | 근거를 비교하고 주제별 결론·의미 있는 연결·남은 질문을 정리한다. 근거 없이 확신을 높이지 않는다. |
| 운영 규칙 | [AGENTS.md](../../AGENTS.md)가 반복 규칙을, [wiki-schema.md](wiki-schema.md)와 [wiki-maintenance.md](wiki-maintenance.md)가 작성·운영 기준을 맡는다. |

외부 원자료와 참고 프로젝트는 기본적으로 읽기 전용이다. 현재 프로젝트의 코드·디자인 작업물은 해당 작업의 승인 범위를 따르며 위키 정리를 이유로 원본을 수정하지 않는다.

## 탐색

[index.md](index.md)에서 관련 주제를 고르고 필요한 근거까지 확인한다. [log.md](log.md)는 중요한 변경의 시간순 이력이며 현재 상태는 주제 문서에서 확인한다.

위키는 파일 저장소의 내용만으로 실제 제품 상태를 보증하지 않는다. 오래된 주장·부분 확인·실행하지 않은 테스트는 그 한계를 유지한다.
