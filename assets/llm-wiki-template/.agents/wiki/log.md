# 위키 변경 이력

실제로 수행한 중요한 지식 변경과 점검 결과를 시간순으로 추가한다. 작성 기준은 [wiki-schema.md](wiki-schema.md#색인과-이력)를 따른다. 현재 상태는 [색인](index.md)에서 해당 주제를 찾아 확인한다.

적용 전에는 완료 이력을 채우지 않는다. 첫 실제 작업부터 아래 형식으로 기록한다.

```markdown
## [YYYY-MM-DD] ingest | 실제 작업의 제목

- 바뀐 지식과 이유: 실제로 확인·반영한 내용.
- 관련 문서: 변경한 주제의 링크.
- 검증과 한계: 실제 확인 범위와 남은 질문.
```
